XANDY PROMPT STUDIO — ANDROID

Este projeto reúne em um único aplicativo:
1) Catálogo de Estilos — 54 estilos, filtro de imagem e estilo para prompt.
2) Xandy 3 Camadas — complemento narrativo + divindade + movimento artístico.
3) Deuses 3C — catálogos masculino e feminino, incluindo versões femininas dos deuses masculinos.

FUNCIONAMENTO
- Conteúdo 100% local/offline dentro do APK.
- Botões de copiar usam a área de transferência nativa do Android.
- O botão voltar do Android retorna ao menu principal.

COMO GERAR O APK SEM ANDROID STUDIO
1. Crie um repositório no GitHub.
2. Envie TODO o conteúdo desta pasta android para a raiz do repositório.
3. Abra Actions > Gerar APK Xandy Studio > Run workflow.
4. Quando terminar, abra a execução e baixe o artefato “Xandy-Prompt-Studio-APK”.
5. Dentro dele estará app-debug.apk.

Pacote: com.xandyaiart.studio
Nome: Xandy Studio
Android mínimo: 7.0 (API 24)
